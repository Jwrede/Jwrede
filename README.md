# Jonathan Wrede

Machine Learning Engineer based in Muenster, Germany. Joining Possehl Digital Services as Data & AI Solution Engineer in January 2027.

I build and ship production machine learning and data platforms end to end, from the estimation library through Kubernetes to the dashboard, and build public tooling for LLM cost, latency, and production readiness.

## What I do

- ML and data platforms: Python, SQL, dbt, Dagster, Polars, FastAPI
- Production operations: Kubernetes, Helm, ArgoCD, Prometheus, Grafana, OpenTelemetry
- LLM application tooling: cost, latency and readiness checks, benchmarking

## Selected proof

- Sole developer of an end-to-end battery analytics platform for 100,000+ IoT devices: a tested capacity/runtime library, Dagster ingestion, FastAPI services, dashboards, and monitoring, across 8+ repositories, integrated into the company Vue dashboard.
- 15+ merged OSS PRs in [llm-d](https://github.com/llm-d/llm-d-router/pull/1099) (router, inference-sim), [OpenTelemetry](https://github.com/open-telemetry/opentelemetry-python-contrib/pull/4554), and [Feast](https://github.com/feast-dev/feast/pull/6362), with active open contributions in llm-d-kv-cache and llm-d-benchmark.

## Open-source tooling

- [battery-passport-kit](https://github.com/Jwrede/battery-passport-kit): create, validate and check EU battery passports (Regulation 2023/1542) with the BatteryPass-Ready data model.
- [aipreflight](https://github.com/Jwrede/aipreflight): production readiness gate for LLM/RAG services (eval, cost, latency, SLA gates).
- [llmprobe](https://github.com/Jwrede/llmprobe): synthetic monitoring and CI smoke tests for LLM inference endpoints.
- [tokentoll](https://github.com/Jwrede/tokentoll): LLM cost diffs in code review.
- [llm-bench](https://bench.jonathanwrede.de): live benchmark for OpenAI-compatible LLM APIs (TTFT, latency, throughput, errors).
- [claude-code-gc](https://github.com/Jwrede/claude-code-gc): removes unused Claude Code versions that fill up dev-box disks.
